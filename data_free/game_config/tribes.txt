# Every tribe and its friend/foe graph. Was hardcoded in tribe.cpp Tribe::generateTribes(); now content.
#
#   "NAME" { enemyOfAll = true  allies = { "OTHER" ... }  diplomatic = true|false  keeperTribe = true }
#
# ONE UNIFORM SHAPE, ON PURPOSE. Every tribe below is `enemyOfAll = true` and then names the tribes it is
# FRIENDLY with. Nothing is left implicit:
#
# - enemyOfAll  = hostile to every tribe that exists, including ones added later by a mod. A tribe is never
#                 hostile to itself, so this is safe on its own.
# - allies      = the exceptions, applied AFTER all hostility is wired, so an ally link can never be undone
#                 by someone else's enemyOfAll. MUTUAL -- listing GNOME under DARK_KEEPER also makes
#                 DARK_KEEPER an ally of GNOME. Both sides are spelled out anyway so each entry reads alone.
# - enemies     = no longer used here. It is still supported (and still mutual) if you prefer the old style,
#                 but mixing the two is what made this file hard to read: see the commented original below.
# - diplomatic (default true): tracks per-creature standing -- attacking one member turns that individual
#                 hostile. A non-diplomatic tribe is purely static friend/foe.
# - keeperTribe = a player-keeper tribe. Its minions dig only where ordered and never use hostile-dig.
#
# WHY THIS SHAPE: with enemy lists, ADDING a tribe meant editing every other entry that should hate it, and
# forgetting one silently made them friends. Here a new tribe is hostile to everything by default and you
# only ever add it to the `allies` of whoever should tolerate it -- one edit, in one place, and never a
# silent friendship. The graph below is IDENTICAL to the enemy-list version it replaces (verified with
# `keeper.exe --dump_tribes`, which prints the full matrix -- diff it before and after any edit).
#
# The engine references some of these ids by name (see tribe.h: MONSTER, HOSTILE, DARK_KEEPER, WHITE_KEEPER,
# RETIRED_KEEPER, INVADER, WILDLIFE, PEACEFUL, PEST, HUMAN, BANDIT). Do not rename those. ELF, DARK_ELF,
# DWARF, GNOME, LIZARD, GREENSKIN, ANT and SHELOB are referenced only by content, so they are yours to change.
